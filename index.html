Using this browser

  

    Drop the Cythera installer (.sit or Cythera.bin) anywhere
    on this page to open the whole game, or a Cythera Data file on its own — the
    .hqx as downloaded is fine, as is a MacBinary or AppleSingle copy. Whatever you
    open is remembered, so the next visit needs no network. Press ? for the keyboard
    shortcuts, / to search. The address bar tracks where you are, so any view can be
    bookmarked or sent to somebody.
