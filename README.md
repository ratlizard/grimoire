Browser-based tools to explore and edit the files of *Cythera* (1999), the
classic Mac RPG by Glenn Andreas and Ambrosia Software.

Open <https://ratlizard.github.io/grimoire>, or download this
repository and double-click `index.html`: the pages are plain HTML and
classic scripts and run from a file as well as from a server. Drop the game's
installer or its `Cythera Data` file on the page, or let it fetch the installer
from archive.org.
